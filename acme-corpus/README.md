# acme-corpus/

The seed dataset every recipe's `demo_queries` resolve against — 25–40 documents across Engineering, HR, Sales, and Support, plus a seed/teardown script for the Indexing API. Populated by **PACT-438** (Cookbook W0.3).

The seed script doubles as the working code for the `index-custom-source` recipe (PACT-444), so this directory is itself a runnable example, not just fixture data.
