# build-engineering-portal

This is an integration recipe for an existing engineering portal, not a standalone scaffold. It composes
[the Indexing SDK quickstart](https://developers.glean.com/libraries/indexing-sdk/quickstart) (index the service catalog)
with the Web SDK embed steps documented in
[embed-search-chat](https://developers.glean.com/cookbook/embed-search-chat).
The cookbook command asks for the existing portal project and stops for the required datasource and
authentication setup. See the full walkthrough at
[developers.glean.com/cookbook/build-engineering-portal](https://developers.glean.com/cookbook/build-engineering-portal).
