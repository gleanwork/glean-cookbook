# company-answers

The hello-world of Glean apps: one page, one input, one permission-aware cited answer — built two ways so you can pick the trade-off that fits.

- **[`web-sdk/`](web-sdk/)** — Glean owns the UI. One `renderChat` call.
- **[`chat-api/`](chat-api/)** — you own the UI. One `chat.create` call, server-side.

See the full recipe writeup at [developers.glean.com/cookbook/company-answers](https://developers.glean.com/cookbook/company-answers) (flag-gated pre-launch) or `docs/cookbook/company-answers.mdx` in the [glean-developer-site](https://github.com/gleanwork/glean-developer-site) repo.
