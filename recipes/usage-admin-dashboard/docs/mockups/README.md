# Visual mockups

These are captures of the runnable recipe, not a separate proposed app. All people, clients, models, consumption, and policies are fictional. Captured on October 12, 2026.

- [Overview](overview.png): customer brand, separate usage units, daily observed chart, model drill-down, and explicit unknown freshness.
- [People](people.png): paginated directory, department filter, and per-person entry point.
- [Policy review](limit-review.png): configured/live distinction, exact spend client, supported and gated targets, review-before-apply.
- [Organization explorer](organization.png): directory manager forest; no inferred IdP or subtree policy.
- [API test bench](api-test-bench.png): read-only request replay and snapshot paging.
- [Narrow layout](narrow.png): navigation and dashboard at 600px width.

The sample respects system light/dark mode. Desktop light and dark, narrow layout, a sample save/read-back/evaluate flow, and API cursor continuation were checked in the browser. No live API or policy mutation is implied by these captures.
